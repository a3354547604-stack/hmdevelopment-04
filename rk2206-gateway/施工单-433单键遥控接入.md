# 施工单：433 单键遥控接入（SOS）

> 目标：**一个按键的遥控器**按一下 → 网关立刻知道 → 上报 SOS。
> 模块：火蝠 H34R 12 路学习型接收板（丝印左列 `KEY/D3/D2/D1/D0/PD/GND/VCC`，右列 `D4–D11`，
> `ANT` 焊盘，背面有学习键 + 32.768 k 晶振）—— 丝印来自实物照片，模块本身没有手册。
> 我们**只用 D0 这一路**（学习型接收板学一路就只占一路），引脚口径**不动**：
> `rk2206-gateway/src/gw_config.h:30` `GW_PIN_433_DAT = GPIO0_PA2`（E53 排针 **A2**），
> 别名在 `rk2206-gateway/src/gw_config.h:181` `GW_PIN_433 = GW_PIN_433_DAT`。

## 0. 这次要验的判据（J1–J4）

| # | 判据 | 怎么看出来 |
|---|---|---|
| J1 | 模块供上电、D0 电平能被网关读到 | 串口每 5 s 一行 `[433] pb0=<0\|1>`（t145 新增） |
| J2 | 遥控器按键能改变这条电平 | 按住遥控时 `pb0=` 与松手时**不同** |
| J3 | 一次按键只算一次触发（3 s 去重） | 串口 `433` 命令里 `trigger` +1，`last=` 归零后重新数 |
| J4 | 触发真的进了 SOS 链路 | 串口出现 433 求助 → SOS 的日志，服务器/App 收到事件 |

## 1. 接线（3 根线）

| 模块丝印 | 接到网关 | 说明 |
|---|---|---|
| `GND` | E53 排针 `GND` | **必须共地**，不接则电平悬空、读数乱跳 |
| `VCC` | E53 排针 `3V3` | 模块 3.3 V 供电（本模块按 3.3 V 用） |
| `D0` | E53 排针 **`A2`** | 我们只学这一路；A2 = `GPIO0_PA2` |

不接：`KEY`（学习键用模块板上的实体按键）、`D1–D11`、`ANT`（板载天线焊盘，不要动）。
排针位置见同目录 `E53座引脚-底板原理图U6.png`（这张是**底板原理图**，不是本模块手册）。

⚠ 先接线后上电。带电插拔杜邦线容易把 PA2 打坏（PA2 没有串电阻保护）。

## 2. 学习配对（3 步）

1. **断电**，按 §1 接好 3 根线，再上电。
2. 按一下模块上的**学习键**（板上 `KEY` 丝印旁边那颗小按键）→ 模块 LED 常亮（有的批次是慢闪）。
3. 在 10 s 内按一下遥控器**唯一那个按键** → LED 快闪两下后熄灭 = 这一路（D0）学到了。

判读：LED 全程没反应 = 学习键没按到 / 模块没供电；LED 闪一下又灭就停 = 没收遥控器信号
（换遥控器电池、靠近到 1 m 内重来）。

【待验证线索】学习键位置与“闪两下”来自同类 12 路学习板的通行做法，**不是本模块手册**。
以实物 `KEY` 丝印为准；闪法不一致时，以“按遥控器后 LED 有反应”为成功判据。

## 3. 上电自检（先别按遥控，只看线通不通）

串口 115200 8N1，复位，等 5 s 应看到（t145 新增的三行）：

```
[gw] 433 采样就绪：[433] mode=edge level=1 edges=0 last=- trigger=0 dedup_ms=3000
[gw] 433 采样 50 ms，每 5000 ms 打印 pb0=（mode=edge）
[433] pb0=1
```

- `level=`/`pb0=` 的初值取决于模块静止时的输出，**0 或 1 都对**，重要的是它“会动”。
- 想确认线真的通：把 D0 那根线从 A2 拔掉再插回（或给模块断电再上电），`pb0=` 应随之变化。

## 4. 按遥控器（最终判据）

按住遥控器按键不放：

```
[433] pb0=0                      ← 具体是 0 还是 1 取决于模块极性，会变就说明收到了
```

松手后回到另一个电平。再敲串口命令 `433`：

```
[433] mode=edge level=1 edges=2 last=1234ms trigger=1 dedup_ms=3000
```

- `edges=2`：按下 1 次变化 + 松开 1 次变化（edge 模式两个方向都算“稳定变化”）
- `trigger=1`：3 s 去重后真正被认下的一次触发
- `last=1234ms`：距刚才那次触发过了多少毫秒；`last=-` 表示还没触发过

## 5. 判读表（现象 → 结论 → 下一步）

| 现象 | 结论 | 下一步 |
|---|---|---|
| `[433] pb0=` 一直不变，按遥控也不变 | 线没接 / 接错脚 / 模块没供电 | 万用表量模块 `VCC`–`GND` 应 3.3 V；再量 `D0`–`GND` |
| `pb0=` 会随按键变，但 `edges` 一直是 0 | 采样任务没起来 | 看开机有没有打 `433 采样任务创建失败` |
| `edges` 涨，`trigger` 不涨 | 3 s 内连按被去重；或毛刺被判成“还在抖” | 隔 5 s 再按一次；仍不涨把模式改 `low`/`high` 试 |
| 一上电 `trigger` 就涨了 1 | 基线采样那一刻模块输出低（未接/常低） | 检查 D0 是不是接到了 GND |
| `pb0=` 每 5 s 在 0/1 之间乱跳 | 没共地，电平悬空 | 把 `GND` 那根线重新压紧 |

## 6. 模式切换（只有 edge 出现怪现象时才需要）

`rk2206-gateway/src/gw_config.h` 的 `GW_433_TRIGGER_MODE`：

| 值 | 含义 | 什么时候用 |
|---|---|---|
| `GW_433_TRIGGER_EDGE` | **默认**：电平稳定变化即触发（高/低有效都收） | 不知道模块极性时 |
| `GW_433_TRIGGER_LOW` | 低电平有效（原语义，干接点/OC） | 确认模块是拉低输出 |
| `GW_433_TRIGGER_HIGH` | 高电平有效 | 确认模块是拉高输出 |

改完重编重烧（`tools/gw-build.sh gateway`）。三种模式的 3 s 去重窗口相同（`GW_433_DEDUP_MS`）。
