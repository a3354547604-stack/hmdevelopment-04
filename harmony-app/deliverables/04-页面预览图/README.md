**怎么来的**：DevEco Studio 26 的预览器（ArkTS 预览构建 + 预览面板截图），**不是真机截图**。
拍摄方法记录在仓库 `tools/`（`preview-build.sh` 构建、`preview-now.ps1` 截面板）。

**能证明什么**：这是 App 真实的 ArkUI 渲染结果——布局、字号、颜色令牌、图标都是跑出来的，
不是画出来的。比 `old-20261022/` 里的 HTML 复刻强得多。

**不能证明什么**：
1. **不是真机**：没有系统状态栏、手势条、键盘避让、真实 DPI 缩放。
2. **02/03 两张里的数据是历史演示数据**（2026-10-31 时 App 还有本地演示数据源，现已删除，
   改为只连真实服务器）。所以图里的「厨房 燃气 正常 / 卧室 跌倒 正常 / 老家 院子 联系不上」
   **不能作为"真实数据长这样"的证据**，只作界面样式证据。新数据要真机/模拟器连服务器后实拍。
