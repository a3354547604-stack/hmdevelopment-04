# 现场装机说明（一页纸）

面向**现场操作的人**：装机、演练三类错误、2.4G 与切网。技术细节与构建见 [`BUILD.md`](BUILD.md)，
本页只写「手怎么动、眼睛该看到什么」。前提是已经有一个 debug APK
（`android-app/app/build/outputs/apk/debug/app-debug.apk`；构建见 BUILD.md §2）。

---

## 1. 装到手机上

```bash
adb install -r android-app/app/build/outputs/apk/debug/app-debug.apk
```

* 手机没开 USB 调试：把 APK 拷进手机，点它安装，允许「安装未知应用」即可。
* debug 包的 `applicationId` 带 `.debug`（`com.hmprogram.eldercare.provision.debug`），
  可以和正式包**同时装**——现场留后路。
* 装完先开一次，确认首页四个按钮都在（添加设备 / 配网 / 开发者设置 / 日志）。

## 2. 没有硬件时：开 MOCK 演练

1. 首页 →「**开发者设置**」→ 勾上「**MOCK 模式**」→ 保存（会提示**重启 App 生效**）→ 杀掉重开。
2. MOCK 下的固定口令：服务器 `Passw0rd`、绑定码 `482913`；网关热点 `ElderCare-1A2B`。
3. 想演练错误码，按下面三行走（MOCK 走的是**同一套信封解析与错误码路径**，不是假返回值）：

| 错误码 | 现场怎么做 | 屏幕上该看到 |
|---|---|---|
| `1602` Wi-Fi 连接失败 | ② 步 SSID 填一个名字里带 `5G` 的（如 `HOME-5G`）→ 提交 | 红字 `1602`，`reason=not_found`，提示要 2.4G |
| `1604` 节点不在扫描列表 | ④ 步点「扫描」，列表刚冒出节点（还在转圈）时**立刻**点某个「绑定」 | 红字 `1604`，提示「先扫描 / 重新扫描」 |
| `1606` 白名单已满 | **MOCK 里复现不了**（只种了 3 个节点且按 MAC 去重，到不了上限 8） | 用真网关复现；或临时把 `MockTransport.kt` 的 `bound.size >= 8` 改小演一次，**演示完必须改回** |

> MOCK 绿 ≠ 网关固件对。它只证明 App 的解析与错误码路径是对的，上真机务必再跑一遍 B2 全流程。

## 3. 家里的 Wi-Fi 必须是 2.4 G

* 5 G 热点配不上（现场最常见的坑）——SSID 里带 `5G` 会稳定复现 `1602`，演示时正好用它讲这一点。
* 口令是 **8–63 字节的 WPA2-PSK**；开放网络（无口令）当场就被拒：
  `400 code=1602 reason=open_not_supported`，不用等超时。
* 目标 SSID 不在网关扫到的列表里（且不是隐藏网络）→ `400 code=1602 reason=not_found`，**不落盘**。

## 4. 提交家庭 Wi-Fi 之后：手机要切网

顺序别搞反，现场最容易卡在这一步：

1. ② 步提交后看到 `settle_s=90` —— 说明网关**受理了**（不是已经连上）。
2. 网关随后**关掉自己的 `ElderCare-XXXX` 热点**，转去连家里的 Wi-Fi —— 手机这时会**掉线**，
   系统可能弹「已连接，无法访问互联网」或直接断开，**这是正常的**。
3. 手机**切回家里的 2.4 G Wi-Fi（或蜂窝网络）**，回到 App 继续 ③ 绑定账号、④ 扫描节点。
4. 万一网关连不上（认证失败/超时）：它会在 **30 s 内退回 AP 模式**并把配网窗口重置为 **600 s**，
   手机会重新看到 `ElderCare-XXXX` —— 连回热点重试即可（错误码 `1602`，`reason=auth`/`timeout`）。

## 5. 上台前 5 分钟自检

- [ ] 配对键长按 **≥3 s**，看到/听到**声光双闪 2 次**（进了配网窗口，默认 600 s）
- [ ] 扫到 `ElderCare-XXXX`；热点口令在**网关贴纸或串口日志**上
- [ ] 连上热点后弹「无法访问互联网」→ 忽略，继续
- [ ] 提交 **2.4 G** 家庭 Wi-Fi → 出现 `settle_s=90` → 手机切回家里的网络
- [ ] ③ 网关 SN（`M0-XXXXXX`）+ 绑定码 → 绑定成功
- [ ] ④ 扫描 → 逐个绑定节点；扫不到就看日志区的错误码原文（1600/1601/1604/1605/1606 都有中文提示）

## 6. 排障：日志与字段核对

* **App 日志区**：每条带时间戳与错误码原文，右上角「**复制日志**」一键复制整段——排障不用拍照。
* **核对网关 H5 页面字段**（H5 是 P0 主路径，写错字段名浏览器只在控制台静默出错）：

  ```bash
  python3 android-app/tools/check_local_api.py --js rk2206-gateway/web/index.html
  ```

  输出 `一致：…` 退出码 0；出现「调用了 §12 之外的本地接口」或某个字段名不在契约里 → 退出码 1。
