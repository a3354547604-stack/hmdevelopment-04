### 2.1 新增

* **`core/AppConfig.kt`** —— 全 App **唯一**允许出现服务器地址、`/api` 前缀、`payload` 字段名、
  演示账号的地方（`SERVER_BASE`、`PATH_PREFIX`、`GATEWAY_BASE/HOST`、`FIELD_READING_DETAIL`、
  `DEMO_USER="13800000000"`、`DEMO_PASSWORD="demo-pass-123"`、`ADVANCED_TAPS=5`、`SCHEME`）。
  它存在的**唯一目的**是让「普通用户界面里不许出现技术词」这条规矩能用一条 grep 守住（见 §5）。
* **`core/DeviceQr.kt`** —— `parseDeviceQr()` 从旧 `ui/MainActivity.kt` 迁出（`CoreRulesTest` 仍在测它）。
* **`ui/LifeText.kt`** —— 技术词 → 生活话的**唯一**翻译层：`statusCard()`（大字卡三种句式）、
  `roomName()`（M1/M2/M4 → 卧室/厨房/门厅，未知 → 家里）、`gasText()/gasLevel()`（正常/偏高/很高，
  1500 mV / 2500 mV 两档取自契约 §4.3）、`alertTitle()`（有人摔倒/燃气浓度偏高/…）、
  `reminderLine()`（`14:32 · 厨房 · 燃气浓度偏高`）、`deviceStateText()`（设备正常/设备失联）、
  `tempText/humiText/doorText/presenceText/yesNo/hourText`、`OFFLINE_HINT`。
* **用户页**：`HomeActivity`（大字状态卡 + 厨房/卧室/门厅三张房间卡 + 今天小结，10 s 轮询 + 下拉刷新）、

## 5. 「源码里没有技术词」证据

```bash
$ bash -c "! grep -rnE 'http://|payload|阈值|节点|MQTT|IoTDA|/api/' android-app/app/src/main \
    --include=*.kt --include=*.xml | grep -v 'AppConfig\|ApiPaths\|//\s\|xmlns' "
$ echo $?
0        # 取反成功 = 扣除豁免后没有任何命中（0 行输出）
```

豁免只有四类，且都在验收方与 captain 的书面口径里：`core/AppConfig.kt`（地址/字段名的唯一存放处）、
`core/ApiPaths.kt`（契约路径表）、注释行（`// ` 开头）、XML 命名空间（`xmlns`）。
XML 注释（`<!-- -->`）**不在**豁免里，所以 `network_security_config.xml` 的注释也一并改写成无地址表述。

## 6. 已知限制（据实登记）

1. **修改密码是「验明本人 + 明确告知」而不是真改**：服务器没有改密接口（`server/app/routers/` 只有
   auth 的 register/login），任务禁止改服务器，所以 `ChangePasswordActivity` 先用 `login()` 校验当前密码，
   通过后明确提示「服务端暂不支持在线改密」。**没有发明接口**。
2. **手机提醒开关是 App 本地静音**：契约 §4.5 有 `mute_alarm` 命令，但 §6 没有暴露 REST 接口，
   App 无法下发；因此开关只写本机（`SessionStore.muteUntil`，24 h）+ 调 `pushRegister`，
   界面上说的是「手机不再响」，不是「网关不再推」。
3. **无真机截图**：本机没有可用的 Android 设备/模拟器，页面证据是「布局 id ↔ 文案」对照 + 纯逻辑单测
   （`LifeTextTest`、`MockFlowTest`）。真机截图与手感（下拉刷新、软键盘、大字体）列入 `BUILD.md §8` 待实测。
4. **`payload` 只是源码里改名**：对外 JSON 字段仍是契约里的名字
   （`@SerializedName(AppConfig.FIELD_READING_DETAIL)`），服务器与网关不需要任何改动。
5. **演示模式入口藏在「连点版本号 5 次」**：这是规范要求，但也意味着现场演示前要先点 5 下——
   `BUILD.md §5` 已把这条写成现场步骤。

## 7. 构建方法（可复现）

```bash
export JAVA_HOME=$HOME/toolchains/jdk17
export ANDROID_HOME=$HOME/toolchains/android-sdk
cd android-app
$HOME/toolchains/gradle-8.7/bin/gradle --offline --max-workers=2 \
  -I "$(pwd)/tools/wsl-build-dir.init.gradle" :app:testDebugUnitTest
$HOME/toolchains/gradle-8.7/bin/gradle --offline --max-workers=2 \
  -I "$(pwd)/tools/wsl-build-dir.init.gradle" :app:assembleDebug
```

WSL 下必须带 `-I tools/wsl-build-dir.init.gradle`（DrvFs 不支持 AGP 8.4 对 jniLibs 输出目录的访问），
构建目录因此落在 `~/eldercare-build/`；Windows 原生 / Android Studio 不需要这个参数。
