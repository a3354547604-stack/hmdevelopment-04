## 3. 页面预览说明（无真机截图，给结构与文案）

本机没有已连接的真机/模拟器（`adb devices` 为空、WSL 内无 emulator），所以**没有真机截图**。
下面按页面给出「进页面看到什么 / 点什么 / 出错看到什么」，并附布局 id，便于按图验收或补拍截图。
android-app 的界面全部是 `LinearLayout` + `TextViews`（无图表库），静态结构与下面文字一致。

### 3.1 登录 / 注册（F5）

顶部标题「登录」/「注册」；服务器地址提示行（点一下进开发者设置，可开 Mock）；
账号、口令（注册时还有手机号，选填）；主按钮「登录」；「没有账号？去注册」；「跳过登录（只做配网）」。
* 登录成功：JWT 写 `SharedPreferences`，进首页；
* 401/1101：清令牌 + toast「登录已过期，请重新登录」+ 回登录页（唯一出口 `BaseActivity.handleFailure`）；
* 本地校验：账号 3–32 位、口令 8–64 位，不合法不发请求。

### 3.2 首页（F7）

顶部（MOCK 时）黄色横幅「MOCK 模式：数据全部来自本地假数据」；离线时红色横幅「离线：…」。
账号行；设备名；在线行 `在线｜心跳 12 秒前｜报警状态 正常｜待处置 2 条`；告警提示行。
**14 属性**两列（键名 / 值）：`有人/无人`、`最近活动 3 分钟前`、`门 关`、`窗 关`、`温度 24.5 °C`、
`湿度 56.2 %RH`、`燃气 320 mV`、`液化气 未上报`、`一氧化碳 未上报`、`节点在线 M1✓ M2✗`、
`电池 市电供电`、`报警状态 正常`、`已绑定节点 M1、M2`、`配网状态 已联网`。
**节点列表**：`M1 · 卧室｜在线｜RSSI -45｜电量 87%`。
按钮：告警 / 报表 / 设置 / 设备 / 添加设备 / 扫码 / 开发者设置 / 退出登录。**下拉即刷新，10 s 自动刷新一次**。

### 3.3 设备绑定（F6）

设备卡片（名称、SN、角色、在线、未读告警）+「去配网」「复制 SN」；点卡片=切换当前设备。
底部「绑定新设备」：对话框三个输入（SN / 6 位绑定码 / 名称可选）。
* 失败时**结果行显示完整三段**：服务器 `message` + 契约操作提示 + data 明细，
  例如 `绑定码错误（HTTP 400 / code 1201）` + `缺少必填参数：bind_code` / `参数 bind_code 允许范围：6 位数字`；
* 扫码：ZXing 扫 SN 二维码（URL/JSON/裸 SN 三种都认）。

### 3.4 告警列表（F8）/ 详情（F9）

列表页：状态下拉（全部/待处置/已确认/已处置）、类型下拉（全部/跌倒/燃气/紧急求助/无活动/节点离线/
网关离线/门久开/环境异常）、`共 N 条，已显示 M 条`；每行标题（如「厨房燃气泄漏报警」）+ 元信息
（级别、时间、节点、推送次数）；「加载更多」按 total 判断显隐。
详情页：标题、元信息（+推送次数/下次推送）、处置历史（动作 + 备注 + 时间，空则「暂无处置记录」）、
备注输入、四个按钮（已联系老人/已上门查看/误报/其他）、处置结果行、告警前后各 5 条读数。
处置成功 → 回列表自动刷新；重复处置 → 1301「告警已处置」并显示在结果行。

### 3.5 周报 / 月报（F10）

周报/月报切换 + 刷新。**对比卡片第一行永远是 `compare.title`**（服务端缺省时本地兜底「今日活动频次」）；
第二行 `今天 N 次`；第三行 `昨天 N 次`（无基线显示 `—`）；第四行 `变化 +12%`（无基线 `—`）；
说明行：有基线用 `compare.text`，无基线用 title 并补一行
「暂无对比数据（无昨日基线：新设备或统计首日）」。
汇总卡片：活动（总次数/活跃天数/日均/高峰/低谷）、告警（总数/已处置/待处置/误报/按类型）、
环境（温度均/最低/最高、湿度均）。活动序列卡片：周报 7 行、月报 30 行；无数据「暂无数据」。
三个接口**各自降级**：任一段失败只影响该卡片，不白屏。

### 3.6 设置（F11）

账号行；设置来源行 `设置来源：device / 已生效到网关（source=device）/ 上报周期：60 秒`；
**21 键**逐行（标签 + 单位、允许范围与提示、输入框、单行「保存」）：无活动判定、有人保持、离家判定、
开门报警、上报周期、节点离线超时、网关离线超时、燃气一/二级阈值、一/二级持续、恢复阈值/保持、
告警抑制、跌倒抑制、温湿度持续、温度上/下限、湿度上/下限、重复推送间隔（`0,60,300` 数组）。
底部：全部保存、下发到网关（显示 `已下发 N 项｜被拒 …｜等待网关回执 30 s` + command_id）、
静音（30 分钟 / 60 分钟 / 取消静音，显示剩余分钟）、演示事件（燃气泄漏 / 跌倒 / 紧急求助）、
Mock 开关、接口自检、开发者设置、退出登录。
* 越界/未知键在本地就拦下并提示允许范围，服务端 1002/1003 也会把 `field`/`allowed`/`key` 显示出来。

### 3.7 接口自检（F12）

逐行 `✓ GET /health  ok v1.0 db=ok` / `✗ GET /devices  网络请求失败：…`；顶部「通过 14 项，失败 0 项」。
Mock 模式下额外跑写接口（PUT 设置 / 下发 / 演示 gas / 处置），真服务器只读，避免污染现场数据。

### 3.8 配网（F1–F4，保持现状 + 对齐）

① 连热点引导（热点前缀、口令、系统设置入口）→ ② 选家庭 Wi-Fi：**先列网关 `/api/scan` 缓存**
（显示 RSSI 与信道，5G 标红；缓存为空提示「网关还没有扫描缓存」并落到手机扫描/手输；
手机不在热点上也**不弹错**，直接降级）→ 口令 → 提交 → 结果 → ③ 绑定账号 → ④ IoTDA 三件套
（接入地址/端口/设备 ID/密钥，可跳过；提交后回显「接入地址 host:port｜设备 id｜密钥已保存」）
→ 节点扫描与绑定 → 现场日志（可复制）。

## 6. 已知限制（写清楚，不藏）

1. **静音是 App 本地实现**：契约 §6 没有 `mute_alarm` 的 REST 入口（§4.5 只有网关命令），鸿蒙侧也只留了开关位。
   这里做「静音到某时刻」的本地状态，不改服务器数据，不发明接口。
2. **`GET /api/scan` 尚未进契约表**：`rk2206-gateway` t143 已实现（只读缓存），清单 F2 明确要求用它；
   App 侧按固件实际响应解析（`cached/scanned_at/age_ms/count/limit/list[{ssid,rssi,ch}]`），
   网关不可达或缓存为空时自动降到手机扫描 + 手输。
3. **无真机截图**：环境没有已连接设备，页面证据以「布局 id + 文案 + 单测」给出；用户接到真机后可直接补截图。
4. **Mock 的 `1606`（白名单满）复现不了**：与 0.1.0 相同，mock 只种 3 个节点。
5. **下拉刷新为自绘**：离线依赖缓存里没有 `androidx.swiperefreshlayout`，为避免新增依赖手写了一个最小实现，
   真机手感需用户确认。
