## 2. 硬约束（不可违反）

1. **不影响电脑其他东西**：
   - 不改 Windows 系统设置、不装 Windows 驱动/软件、不动注册表、不动其它盘。
   - 不重启电脑；不占用交互式 COM 口太久（烧录时短暂占用是必要的）。
   - 不 `git commit` 之外破坏仓库既有文件；已写好的文档（计划/评审/证据）**只增不改语义**。
   - 长时间下载/编译用后台任务，不要刷屏；不要开一堆常驻进程。
2. **优先 Docker**（在 WSL 里跑编译），避免污染 WSL 系统环境；Docker 不可用才退化为 WSL 原生安装。
3. **板子一直插着**：串口是 **COM14**（`USB-SERIAL CH340`）。所有串口操作通过 `powershell.exe` + .NET SerialPort（WSL 看不到 /dev/ttyUSB）。
4. **必须可回滚**：刷自研固件会覆盖 XF_AT。
   - 先下载/保存官方 XF_AT 固件包（`.fwpkg`）到本地，确保能刷回。
   - 记录刷写前的固件版本：`XF_AT-V2.1.13-d`，编译于 `2025-12-23 15:18:01`。
   - 如果刷砖：用 BurnTool / ws63flash 重新烧 XF_AT。
5. **不猜**：任何"能不能"的结论必须有实测或官方文档出处；不确定就写"未验证"。
