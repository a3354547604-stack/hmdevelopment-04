## 一、接线（用户 2026-10-16 已判通）

| LD6002C 侧 | WS63（E528H 开发板）侧 | 说明 |
|---|---|---|
| 3V3 | 3V3 | 3.1–3.5V，纹波 ≤50mV，供电 ≥1A |
| GND | GND | 共地 |
| TX0 | IO07（UART2 RX） | 雷达 → WS63 |
| RX0 | IO08（UART2 TX） | WS63 → 雷达（阈值下发/查询） |
| BOOT1 | GND | 拉地，正常启动（不进下载模式） |

固定串口参数：**UART2 / 115200 / 8N1 / TinyFrame 帧**。

## 二、已实测通过（2026-10-16）

- 五根线全部判通：`rx_total` 单调增长，`bad=0`、`drop=0`（首个抓包 113,927 帧无校验错）。
- `0x0E02`（跌倒状态）持续 **~24 帧/s**，`is_fall=0`（无人跌倒时不误报）。
- 参数查询 `0x0E06` 有回包：读回 `high=2.400`、`threshold=0.600`、`sensitivity=10`。
- 证据见原始日志中两个抓包（20 s + 120 s）。

## 三、尚未验证（不得当成已通过）

- **跌倒触发**：需顶装 2.2–3.0m、被检人躺 15–20 s；演示前必须实测一次并留日志。
- **TX2 输出通道**：`IO06` 中断已注册，但 `tx2_edges=0`，未验证。
- 60GHz SRRC 合规：仅有二手信息，未见官方文件（见 `docs/技术笔记/可行性核查-南向-2026-10-17.md`）。

## 四、踩过的坑（别再犯）

- 雷达占用 **GPIO07/08（UART2）**：节点固件的 ADC 只能用 ch2–ch5，ch0/ch1 让给雷达。
- 测试开关 `RADAR_THR_TEST_ENABLE`（`ws63-firmware/src/radar_hub.c:62`）会把阈值 0.6 降到 0.1，仅用于演示触发，测完必须恢复。
- 端口身份不要猜：板 A 曾被枚举成 COM15（旧烧录器写死 COM14），按 USB 实例路径认板。
