### 16.1 星闪 WS63 —— 如般微 E528H-WS63（**本项目实际硬件**）

来源【官方】`docs/如般微WS63/e528h-ws63开发板规格书v01.pdf`、`e528h-ws63-v01原理图.pdf`。模块为 **DIP-30**。

| PIN | 名称 | 复用信号（官方原表） |
|---|---|---|
| 1 | VCC | 3.3V / 5V 供电 |
| 2 | EN | 芯片使能，高有效，模块内默认上拉 |
| 3、4 | GND | — |
| 5 | IO00 | GPIO0 / PWM0 / SPI1_CS_N / TDI |
| 6 | IO01 | GPIO1 / PWM1 / SPI1_IO0 — ⚠️ **禁止外部上拉** |
| 7 | IO02 | GPIO2 / PWM2 / SPI1_IO3 |
| 8 | IO03 | GPIO3 / PWM3 / SPI1_IO1 — **上电前拉高进下载模式** |
| 9 | VCC | 3.3V |
| 10 | IO04 | GPIO4 / PWM4 / SPI1_IO1(SI) / JTAG_ENABLE / POWER_CTRL — ⚠️ **禁止外部上拉** |
| 11 | IO05 | GPIO5 / UART2_CTS / PWM5 / SPI0_IN / SPI1_IO2 |
| 12 | IO06 | GPIO6 / UART2_RTS / PWM6 / SPI0_OUT / SPI1_SCK / REFCLK — ⚠️ **禁止外部上拉** |
| 13、14 | 5V | 供电 |
| 15 | GND | — |
| 16 | IO10 | GPIO10 / PWM2 / **ADC3** / SPI0_CS0_N / I2S_SCLK / ANT0_SW |
| 17 | IO09 | GPIO9 / PWM1 / **ADC2** / SPI0_OUT / I2S_DO / TDO / RADAR_ANT0_SW — ⚠️ **禁止外部上拉** |
| 18 | IO07 | GPIO7 / **UART2_RXD** / PWM7 / **ADC0** / SPI0_SCK / I2S_MCLK |
| 19 | IO08 | GPIO8 / **UART2_TXD** / PWM0 / **ADC1** / SPI0_CS1_N |
| 20 | IO11 | GPIO11 / PWM3 / **ADC4** / SPI0_IN / I2S_LRCLK / RADAR_ANT1_SW — ⚠️ **禁止外部上拉** |
| 21 | IO14 | GPIO14 / UART1_RTS / TCK-SWC / RADAR_ANT1_SW |
| 22 | IO13 | GPIO13 / UART1_CTS / TMS-SWD / RADAR_ANT0_SW |
| 23 | U1TX | **UART1_TX** / I2C1_SDA |
| 24 | U1RX | **UART1_RX** / I2C1_SCL |
| 25 | IO12 | GPIO12 / PWM4 / **ADC5** / I2S_DI / ANT1_SW |
| 26、29、30 | GND | — |
| 27 | U0TX | **UART0_TX** / I2C0_SDA —— 板上接 CH340 |
| 28 | U0RX | **UART0_RX** / I2C0_SCL —— 板上接 CH340 |

**开发板上有什么**（官方规格书表格 4）：

| 项 | 说明 |
|---|---|
| RGB 灯 | **WS2812B，接 IO05** |
| RST 按键 | 复位，接模块 EN，低有效 |
| 强制下载按键 | **供电前**一直按住可上拉至 VCC 进下载模式 |
| Type-C 口 | 供电 + 数据，接 **CH340** 转 TTL 串口 |

⚠️ **开发板只有 RST 与下载两个按键，没有用户按键** → 「按键进入绑定模式」要么**外接按键**到空闲 IO（推荐 `IO13`/`IO14`/`IO12`/`IO10`，避开禁止上拉的 `IO01/IO04/IO06/IO09/IO11`），**要么把按键接在网关 RK2206 上**（更省事，见 §16.3）。

**本项目接线**：

| 用途 | 引脚 |
|---|---|
| WS63 ↔ 网关 RK2206 | `U1TX`(23) / `U1RX`(24) = UART1 —— ⚠️ **但 RK2206 侧 UART1 是底板 CH340E 调试串口（§17.3）→ 改建议用空闲的 `E53_UART0_TX_M0/RX_M0`**（见 §9.1） |
| LD6002C 雷达 | `IO07`(18, UART2_RXD) / `IO08`(19, UART2_TXD) |
| 气体模拟量 MQ-2/5/7 | `IO07`=ADC0、`IO08`=ADC1、`IO09`=ADC2、`IO10`=ADC3、`IO11`=ADC4、`IO12`=ADC5 |
| AHT20（I2C） | ⚠️ **v2.1 更正**：DIP-30 排针上**没有 IO15/IO16** —— I2C1 只复用在 **23 脚 `U1TX`(I2C1_SDA) / 24 脚 `U1RX`(I2C1_SCL)**，与 UART1 同脚 → 用 UART1 的汇聚节点不能同时用 I2C1。到货后请以**实物丝印 + 规格书**再核一遍。（且 XF_AT 根本没有 I2C 指令，见 §9.2） |
| 外接按键（备用） | `IO13` / `IO14` / `IO12` |

### 16.2 WS63 固件路线：**XF_AT，不是 SDK**

【官方原文】（如般微文档「SDK 资料」）：
> 点击跳转至海思官方开源 SDK（**目前暂时不再对 SDK 提供支持，仅对 XF_AT 进行支持**，如需 SDK 方面的支持请联系海思官方社区或社群）

→ 结论：**WS63 不写 C 固件、不编译 SDK**，烧官方 XF_AT 固件，由 RK2206 用串口 AT 指令驱动。
✅ **v2.2（10-16）已改走自研固件**：基于 `gitee.com/HiSpark/fbb_ws63`（Apache/MIT）自研 C 固件，真机实测可读 ADC/GPIO，SLE 服务端已广播（§0.0b、§9.2）。原"XF_AT 无 ADC/I2C、透传暂停 AT 解析"的阻断已解除。

**AT 数据通道**：默认与固件下载同一串口，**115200 / 8 / 1 / 无校验**，可用 `AT+IPR` 修改。

指令清单（【官方】《XF AT 指令使用指南 V2.1.x》/《V2.0.x（WIFI 篇）》）：

| 类别 | 指令 |
|---|---|
| 基础 | `AT+HELP` `AT+RST` `AT+ECHO` `AT+SWINFO` `AT+IPR` `AT+GPIOCFG` `AT+GPIOWR` `AT+GPIORD` `AT+DBGIO` |
| 配置 | `AT+CFG` `AT+CFGSAVE`（**配置存非易失存储，开机自动加载** → 配网参数可留在 WS63） |
| Wi-Fi AP | `AT+APSTART=<ssid>,<pwd>,<channel>,<authmode>[,<mac>]` `AT+APSTOP` `AT+APSHOWSTA` `AT+APDEAUTHSTA=<mac>` |
| Wi-Fi STA | `AT+STACONN` `AT+STADISCONN` `AT+STASCAN=<ch>[,<nonblock>[,<stop>]]` `AT+STASCANRESULT` `AT+STASTATE` `AT+STASTOP` `AT+STASTATR` `AT+STACLEARSCANRESULT` |
| 网络 | `AT+IFCFG` `AT+DHCP` `AT+DHCPS` `AT+DNS` `AT+IPSTART` `AT+IPSEND` `AT+IPCLOSE` `AT+IPLISTEN` `AT+IPLINKSTATE` `AT+IPD` `AT+IPDOMAIN` `AT+PING` `AT+IPERF` |
| BLE | `AT+BLEENABLE` `AT+BLEOBJ` `AT+BLEADDR` `AT+BLENAME` `AT+BLEADV` `AT+BLEADVDATASET/GET` `AT+BLECONNSET/GET` `AT+BLECONNBYNAME` `AT+BLESCAN` `AT+BLESEND` `AT+BLERECV` |
| SLE | `AT+SLEENABLE` `AT+SLEOBJ` `AT+SLECONNIO` `AT+SLEADDR` `AT+SLENAME` `AT+SLEADV` `AT+SLEADVDATASET/GET` `AT+SLECONNSET/GET` `AT+SLECONNBYNAME` `AT+SLESCAN` `AT+SLESEND` `AT+SLERECV` `AT+SLETRAN`（循环透传） `AT+SLEUUID` |

⚠️ **关键约束【官方原文】**：`AT+APSTART` 备注「**暂未支持 AP 与 Station 共存**」→ 配网时开热点、配网完必须 `AT+APSTOP` 再 `AT+STACONN`，**两者不能同时**。所以配网热点放在 RK2206 上开（AP 与 STA 分阶段），WS63 只负责 BLE 信道。

⚠️ **XF_AT 没有 MQTT 指令** → WS63 不能直接上华为云。**架构定版：RK2206 是唯一云出口，WS63 只做无线（星闪汇聚 / BLE / Wi-Fi 透传）。**

**官方配套示程**：`docs/如般微WS63/nearlink-sample/`（原包 `nearlink-kit-sample-xf-at.7z`）= 如般微发布的「**适配 XF AT（从机）的鸿蒙 APP 参考示程**」，即 Nearlink Kit 官方示例（`compatibleSdkVersion 5.0.1(13)`，星闪广播 / 扫描 / SSAP 连接，含 `ScanConfigPage.ets`、`SsapClientPage.ets`、`SsapServerPage.ets`）。⚠️ 它要求**手机本身支持星闪**，属"手机直连星闪"路线 —— 本项目手机不直连星闪，**留作备用与答辩素材**。

### 16.3 小凌派 RK2206 开发环境

来源【官方】<https://gitee.com/Lockzhiner-Electronics/lockzhiner-rk2206-openharmony3.0lts>（根目录 `README_zh.md`）

| 项 | 值 |
|---|---|
| 仓库根 | `applications` `base` `build` `device/rockchip` `docs` `drivers` `foundation` `interface/sdk-js` `kernel` `prebuilts` `third_party` `utils` `vendor/lockzhiner`；根文件 `build.py` `build.sh` `flash.py` |
| Docker 镜像 | **`swr.cn-south-1.myhuaweicloud.com/openharmony-docker/docker_oh_mini:3.2`**（⚠️ 与通晓板的 `openharmony-docker:1.0.0` **不是同一个**） |
| 容器内准备 | `./build/prebuilts_download.sh` → `pip3 install build/lite` |
| 选板编译 | `hb set -root .` 选 **`lockzhiner-rk2206`** → `hb build -f` |
| 产物 | **`out/rk2206/lockzhiner-rk2206/images`**（`Firmware.img` + `rk2206_db_loader.bin`） |
| 烧录（Windows） | **RKDevTool**，USB 线插 **USB-OTG 口（即烧录口）**，**长按 MaskRom 键 → 再点 ReSet 键**约 5 秒进 MASKROM |
| 烧录（Linux） | `device/rockchip/tools/linux/flash.py` |
| 调试串口 | **另一路 Type-C UART**（不是 OTG 口），**115200**，MobaXterm |
| 硬件资料位置 | `vendor/lockzhiner/rk2206/docs/`（子目录 `board` / `datasheet` / `figures`）——**引脚原理图 PDF 在这里，Gitee 网页可在线打开** |

**⚠️ 结论：OTG 口本职是烧录口**——接 SD 读卡器会与烧录冲突。（v2.1 更正：仓库树里**确有** `drivers/adapter/khdf/liteos/model/usb/host`，"无 USB Host 栈"的说法不准确；但**没有 U 盘/读卡器样例、官方从未宣传该用法** → 实践上做不了。）→ **仍放弃外接存储**，断网缓存走板载 8MB FLASH（8MB 已核实；注意与固件同片，需自写环形缓冲与掉电保护）。

### 16.4 小凌派官方 samples —— 本项目的南向积木几乎全有

来源【官方】`vendor/lockzhiner/rk2206/samples/`。**此前担心的"官方云样例是按通晓板写的、小凌派要自己移植引脚"基本解除——小凌派自带一整套 E53 + 华为云样例。**

| 我们需要的功能 | 小凌派现成样例 | 直接拿什么 |
|---|---|---|
| 按键进绑定模式 | `b17_iot_adc`、`b9_gpio` | 小凌派用户键走 **ADC**（原理图网名 `USER_KEY_ADC`） |
| SoftAP 配网（开发板开热点给 App） | **`b14_wifi_ap`** | AP 建热点 + 收 HTTP 请求 |
| **433 按钮接收（GPIO 中断）** | **`b10_gpio_interrupt`**、`b19_iot_gpio_int` | 外部中断 + 消抖；**这是网关唯一直连的传感器式输入** |
| **声光报警（PWM / GPIO）** | `a8_hal_pwm`、`b16_iot_pwm`、`b9_gpio` | 蜂鸣器 3KHz PWM + LED GPIO |
| **DFPlayer 语音（UART2）** | **`b6_uart2`**、`b20_iot_uart` | UART 发 AT 选曲 |
| **接星闪汇聚节点** | `b6_uart0`、`b20_iot_uart` | UART 收发 + 环形缓冲。⚠️ **别用 UART1（那是调试串口，§17.3）**，用 `E53_UART0` 或 UART2 |
| 断网缓存写 FLASH | **`b15_flash`**、**`b21_iot_flash`** | Flash 读写封装（环形缓冲的地基） |
| 设备上云（MQTT + 华为云） | **`d2_iot_cloud_smart_covers`** ~ `d7_iot_cloud_*`（自带 `oc_mqtt`） | 完整云端对接骨架，改设备参数即可。⚠️ 样例是**明文 1883、无 TLS**（§6.5）；⚠️ **`d8_iot_cloud_TH` 是"通鸿"平台样例，不是华为云**；⚠️ 本地课件只到 d1~d7 / c1~c7 |
| KV 存储（存 WiFi 密码） | **`a10_kv_store`** | 配网参数持久化，比裸写 Flash 省事 |
| LCD（可选加分） | `b4_lcd`、`b23_iot_lcd` | 本地显示 |
| 仅作移植参考（**若走路线 A，这些驱动直接跑在 RK2206 上**） | `b11_i2c_scan`、`c5_e53_body_induction`、`c7_e53_intelligent_smoke_sensor`、`c1_e53_intelligent_agriculture`、`c8_e53_temperature_measurement` | D203B 红外、MQ2 浓度换算、SHT30 温湿度 —— 路线 A 直接用在主控；路线 C 才需要搬到 WS63 节点 |

完整清单（仓库已核实）：内核 `a0`~`a10`、外设 `b1`~`b23`、E53 `c1`~`c8`、云样例 `d1`~`d8`。⚠️ 其中 `d1_iot_mqtt` 是 PC 端私服例程，**华为云用 `d2~d7`**；`d8` 属"通鸿"平台。（本地课件 PDF 只到 `d1`~`d7` / `c1`~`c7`）
