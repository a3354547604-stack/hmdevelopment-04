# 小凌派 RK2206 板载按键 K1–K4（ADC 电阻梯）—一手文档取证

> 维护：PM · 建立：2026-10-19 · 状态：**文档已确认，板测标定待做（t138）**
> 起因：用户指出「RK2206 板上有 K1–K4 四个实体按键，独立、PCB 上有丝印」，要求查文档而不是猜。

## 一、结论

**K1–K4 是四个实体按键，经电阻梯接到同一条 ADC 线：`GPIO0_PC5` = `SRADC5` = ADC 通道 5。**
空闲（无按键）约 **2.3 V**；按下时电压分别约为 **K1 0.01 V / K2 0.55 V / K3 1.00 V / K4 1.65 V**（原始文档措辞为 Key1–Key4）。
因此**不需要外接轻触开关**就能做「长按进配网」的入口——这推翻了接线表 §2.5 原先「RK2206 底板没有确认可用的独立用户键」的前提。

## 二、一手来源（全部可在本机取到）

1. **厂商课件**：`docs/小凌派RK2206/board_课程配套课件_b1_OpenHarmony基础外设开发-adc.pdf`（福州市凌睿智捷电子有限公司，2022）第 8 页"03 如何使用 ADC"原文：
   - （1）无按键按下时，电压为 2.3V
   - （2）Key1 按下时，电压为 0.01V
   - （3）Key2 按下时，电压为 0.55V
   - （4）Key3 按下时，电压为 1.00V
   - （5）Key4 按下时，电压为 1.65V
   - 并写明："本课程通过 **4 个按键**来让**一路 ADC** 采集线路电压发生变化" ⇒ 四键共用一路 ADC。
2. **同一 PDF** 的软件说明："在 `adc_process()` 中，通过 `LzSaradcInit()` 将 **`GPIO0_PC5` 复用为 `SRADC5`**，然后每隔 1 秒通过 `LzSaradcReadValue()` 读取。"
3. **SDK 样例** `vendor/lockzhiner/rk2206/samples/b1_adc/adc_example.c:30`：`.gpio = GPIO0_PC5, .func = MUX_FUNC1`；其 README 记：10 位 ADC、量程 0–3.3 V、`实际电压 = 采样值 / 1024 * 3.3`、基准电压选 AVDD（寄存器 `GRF_SOC_CON29` bit[4]=0）。
4. **SDK 样例** `vendor/lockzhiner/rk2206/samples/b19_iot_gpio_int/iot_gpio_int_example.c:24-25`：
   `/* GPIO0_PC5与按键相连 按下K1引脚电压0.06V左右 可作为下降沿触发 */` `#define GPIO_TEST GPIO0_PC5`
5. **SDK 样例** `vendor/lockzhiner/rk2206/samples/b17_iot_adc/README_zh.md`：ADC 通道表 —— 通道 5 = `GPIO0_PC5`（通道 0–7 依次为 PC0–PC7）。
6. 原理图：核心板原理图有 `ADC_KEY` 网络块（`docs/小凌派RK2206/board_硬件原理图_…_核心板原理图.pdf.txt:1015`），底板原理图有 `USER_KEY_ADC` 网名（同目录底板文本 `:396`）——与上表一致。

## 三、实现建议（供 t138 落地）

- 读 **ADC 通道 5**，10 位、按 `值/1024*3.3` 换算电压；分档判定：**空闲 ≥2.0 V**；**K1 < 0.30 V**；**K2 0.30–0.78 V**；**K3 0.78–1.33 V**；**K4 1.33–1.95 V**（各档中心值 ±0.2 V 容差，阈值可配置）。
- 去抖 50 ms；「长按 3 s」与现有 `GW_PIN_PAIR_KEY`（外接 `EX_GPIO_A3`）共用同一条状态机入口。
- 判定逻辑做成纯函数，主机测覆盖：抖动、长按、短按、基线漂移。
- 任意一个键（K1–K4）都可作配网键；若要区分键位，按上表分档即可。

## 四、两处已知出入（**以我们板子的实测为准**）

1. b1_adc 的 README 运行日志打印的是 `vlt:3.297V`（≈满量程），与课件"空闲 2.3V"不一致 —— 可能是电阻梯未贴装/浮空、或引脚复用未生效、或板版不同。
2. `b19` 注释说 K1 按下"0.06V 左右"，课件说 0.01V —— 同量级，取实测值。

⇒ t138 上板时先打印**全部可用通道**的 raw/mV 与**空闲值**，再让用户逐个按 K1–K4 记录按下值，用实测值回填本文与接线表。
