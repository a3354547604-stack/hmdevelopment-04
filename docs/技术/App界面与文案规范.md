# App 界面与文案规范（面向普通用户，不是程序员）

用户原话（2026-10-20）：「这个 App 是给用户用的，不是给专业程序员用的……没有注册按钮，怎么还让填服务器 IP，用户难道要自建服务器吗」

## 0. 三条硬规矩

0.0 **账号 = 手机号 + 密码**（用户 2026-10-20 拍板）：登录页标签「手机号」，校验 11 位数字；注册页三项（手机号/密码/确认密码）。服务器仍按账号字符串存，不改接口。演示账号 `13800000000` / `demo-pass-123`。
0.0b **主要使用者是子女**（用户拍板）：首页大字卡固定句式「**爸妈今天一切都好**」，异常时「爸妈那边有 N 条提醒」/「有紧急情况」。

1. **服务器地址写死**：默认 `http://123.206.99.28/api`，界面上**不出现** IP/端口/API 字样。仅供维护用：设置页连点版本号 5 次才出现「高级」，里面才允许改地址。
2. **注册入口必须显眼**：登录页底部有「还没有账号？立即注册」整行按钮，注册页只有账号/密码/确认密码三项。
3. **一律用生活语言**：界面与提示里禁止出现 `属性 / 节点 / payload / 阈值 / MQTT / IoTDA / 在线离线（技术含义）/ API / 网关` 等词，改用下表。

## 1. 术语对照（必须照用）

| 内部说法 | 用户看到的 |
|---|---|
| 网关、设备 SN | 家里的小盒子 / 设备编号 |
| 节点 M1/M2/M4 | 房间：厨房 / 卧室 / 门厅 |
| 燃气浓度 ppm、阈值 | 燃气 正常/偏高/很高 |
| 跌倒检测 | 有人摔倒 |
| 门磁 | 门（开/关） |
| 温度湿度 | 温度 24℃、湿度 55% |
| 在线/离线 | 设备正常 / 设备失联（请检查电源和网络） |
| 告警 | 提醒 |
| 处置（confirm/resolve） | 知道了 / 已处理 |
| 周报/月报 | 这周 / 这个月 |
| 演示事件 | （仅维护模式可见，普通界面不出现） |
| 静音 | 手机不再响 |
| 上报周期、心跳、属性上报 | （不出现） |

## 2. 页面与导航（两个 App 必须一致）

底部只放三个：**首页 / 提醒 / 我的**。

### 2.1 登录 / 注册
- 大标题「老人守护」，副标题「随时知道爸妈好不好」
- 两个输入框：账号、密码 + 大按钮「登录」
- 下面一行「还没有账号？立即注册」
- 注册页：账号、密码、确认密码 + 「注册并登录」
- 不出现服务器地址、不出现协议说明

### 2.2 首页
- 最上面一张**大字状态卡**：绿色「一切正常」/ 橙色「有 3 条新提醒」/ 红色「有紧急提醒」，下方一行时间「刚刚检查过」
- 三张房间卡：厨房（燃气 正常 / 温度 24℃ / 湿度 55%）、卧室（有人摔倒 无 / 现在有人 是）、门厅（门 关 / 今天开关 6 次）
- 一张「今天」小结：走动 6 次、提醒 1 条、最长无活动 2 小时
- 下拉刷新；断网时顶部黄条「网络不太好，正在重试」

### 2.3 提醒
- 列表，一条一行：`14:32 · 厨房 · 燃气浓度偏高`（按时间倒序）
- 点开详情：一句人话说明 + 两个大按钮「我知道了」「已处理」+ 可填一句备注
- 顶部筛选只保留：全部 / 未处理

### 2.4 我的
- 「家庭成员」：显示已绑定设备「客厅的小盒子 · 设备正常」，按钮「绑定新设备」
- 「手机提醒」：开关（开/关）
- 「修改密码」
- 「退出登录」
- 版本号一行（连点 5 次进高级：服务器地址、演示事件、Mock 开关——**默认隐藏**）

### 2.5 添加设备（配网向导，给子女用）
1. 一句话说明：「先让手机连上小盒子的 Wi-Fi」，按钮「去连接」
2. 选家里 Wi-Fi（下拉，列表没有就手输）+ 密码
3. 「正在连接…」进度页
4. 成功：「小盒子已连上你家 Wi-Fi」，失败：一句话原因 + 「重试」

## 3. 文案示例（必须这么说）

- 成功：「已连上，正在把数据发到云端」
- 失败（口令错）：「Wi-Fi 密码不对，请重新输入」
- 失败（找不到热点）：「没找到这个 Wi-Fi，请确认它离手机不远」
- 设备失联：「小盒子失联了，请检查电源和网络」
- 无数据：「还没有收到数据，稍等一会儿」

## 4. 验收方式（两边一致）

- 全界面截图或预览图里**搜不到**：`http://`、`API`、`payload`、`阈值`、`节点`、`MQTT`、`IoTDA`
- 登录页可见「立即注册」；注册后直接进首页
- 首页无技术字段名，只有房间与生活指标
- 高级功能必须连点版本号才出现
