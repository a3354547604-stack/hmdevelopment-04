# App 功能对齐清单（鸿蒙 App ↔ 安卓 App）

用户要求（2026-10-20）：**两个 App 功能必须完全一致，都保留。**
本文件是唯一口径：任何一侧新增/删除功能，必须先改这里，再改代码。

## 1. 功能矩阵（两侧都必须有）

| # | 功能 | 验收标准（两侧一致） |
|---|---|---|
| F1 | 配网引导 | 引导用户打开手机 WLAN、连接网关热点；显示热点名与「连不上怎么办」三步 |
| F2 | 家庭 Wi-Fi 选择 | 调网关 `GET /api/scan` 拿**缓存列表**，下拉选择 SSID；列表为空时允许手输 |
| F3 | Wi-Fi 密码提交 | 调 `POST /api/provision/wifi`（契约 §12.6）；成功/失败都要有明确文案；失败可重试 |
| F4 | 华为云凭据（**厂商侧，用户不填**） | r5 口径：IoTDA 接入地址/设备 ID/密钥属**厂商侧**（网关维护面板或串口 `gwkv set` 下发）；**App 与配网页都没有这一项**，用户只需 F1–F3 |
| F5 | 登录 / 注册 | 账号密码；JWT 持久化；401 或 1101 自动清令牌回登录页 |
| F6 | 设备绑定 | 列表 + 绑定；绑定失败给服务器 message，不吞错 |
| F7 | 首页实时 | 网关 14 属性 + 节点列表 + 在线状态 + 电池/信号；下拉刷新；10 s 自动刷新 |
| F8 | 告警列表 | 分页、按类型/状态筛选、按时间倒序 |
| F9 | 告警详情 + 处置 | 详情字段齐全；可提交处置（确认/已处理/备注）；提交后列表状态同步 |
| F10 | 周报 / 月报 | `compare.title` 必现；无昨日基线时只显示 title/today 且不报错 |
| F11 | 设置 | 21 键阈值读写、静音、上报周期、演示事件（gas/fall/sos）、退出登录 |
| F12 | 无设备自检 | Mock 模式跑通全流程，页面有入口，结果可截图 |
| F13 | 离线行为 | 断网时给明确提示，不白屏、不卡死 |

## 2. 共同约束

- 服务器地址可配置（默认 `http://<局域网IP>:3000/api`），不写死公网域名。
- 错误提示必须带服务器 `data` 明细（`field`/`allowed`/`missing`/`key`），不能只显示裸 message。
- 演示事件只允许 `gas`/`fall`/`sos`（契约 §6.12），不得出现 door/presence。
- 匿名：不得出现学校/团队/指导老师信息。
- 产物：鸿蒙 HAP（记录体积+提交号）、安卓 APK（记录体积+sha256+提交号）。

## 3. 现状

- 鸿蒙 App（`harmony-app/`）：F5–F13 已实现并有自检；**F1–F4 缺**（原计划放浏览器 H5，现按用户要求进 App）。
- 安卓 App（`android-app/`）：仅 F1–F3 雏形（Kotlin，配网）；**F4–F13 缺**。

## 4. 依赖

- F2 依赖网关 `/api/scan` 返回**开窗前扫描的缓存**（单射频限制，见 `rk2206-gateway/配网实现说明.md` §14）。
- F4 依赖网关本地 API 接受云凭据（已实现 `gwkv set`，HTTP 侧需 `/api/config` 支持）。
