- ⚠️ **口径更正（2026-10-18 由 t76 一手核实，commit `8e9719b`）**：上面「一个字节都没发出去／物理层断链」**是错的**。真因是**判据写反**：`uapi_uart_write()` 返回值是**实际写出的字节数**（SDK `src/include/driver/uart.h:499` 注释 + `src/drivers/.../uart/uart.c:738-763`：`unused(timeout)`、param_check 失败才返负码、正常 `return write_count;`），写成功 n=len>0 反被判失败 → **负数=errcode，非负=已写字节数**；帧一直在发，是「判据 + 日志黑屏」双重掩盖。修法：判据改 `n == (int32_t)len`、新增 `HUB_UART_TX_TIMEOUT_MS 200u`（本 SDK 会丢弃该参数）、失败三级计数 `tx_err/tx_short/tx_param` 进 STAT；上板 150 s（uptime 121 s）判据全满足：`[GLINK] -> 0x01` = **92**、`uart write failed` = **0**、`up_sent=74`、`tx(ok=90 err=0 short=0 param=0)`；交付镜像台架钩子仍 OFF（1473640 B，两次构建 sha256 相同）。
