# 10 分钟拿到华为云 IoTDA 三件套（照着点就行）

> 目的：让网关能连华为云。你只需要**建一个产品 + 一个设备**，把三个值发我，剩下的我用串口写进网关。
> 详细解释在 `docs/执行/IoTDA建产品与设备指引.md`；这份是「手快点」版。

## 一、准备工作
1. 打开 <https://console.huaweicloud.com/iotdm/>
2. 左上角地区选 **北京四**（华北-北京四）
3. 首次进入若提示开通「设备接入 IoTDA」，点开通，选 **标准版 / 按需**（不选包年包月），确认

## 二、建产品（2 分钟）
1. 左侧「设备接入」→「产品」→ 右上「创建产品」
2. 填：
   - 产品名称：`老人守护网关`
   - 协议类型：**MQTT**
   - 数据格式：**JSON**
   - 设备类型：随便填 `gateway`
   - 其余默认 → 创建
3. **不用**建物模型、不用建服务、不用建命令（我们的网关是「自定义 topic + 自定义 payload」，全部走透传）

## 三、注册设备（2 分钟）
1. 左侧「设备」→「所有设备」→ 右上「注册设备」
2. 选刚建的产品；设备标识码填一个固定串，例如 `GW-DEMO-0001`（**这个必须和网关 SN 一致，我会告诉你当前 SN，或者你直接用它**）
3. 认证类型：**密钥**
4. 点「确定」→ 弹窗里会显示 **设备 ID** 和 **设备密钥** → **两个都复制下来**（密钥只显示这一次，丢了就「重置密钥」）

## 四、找接入地址（1 分钟）
左侧「总览」→ 页面右侧「接入信息」里找 **MQTT 接入地址**，形如 `xxxxx.st1.iotda-device.cn-north-4.myhuaweicloud.com`
（如果是 IP 形式也照抄；端口固定 **1883**）

## 五、把这三个值发我
```
接入地址：
设备 ID：
设备密钥：
```
（设备标识码也顺带说一下，必须是 `GW-DEMO-0001` 这种固定串）

## 六、我这边怎么用（你不用管）
串口敲一条命令写进网关：
```
gwkv set host=<接入地址> port=1883 device=<设备ID> secret=<设备密钥> time=123.206.99.28 timeport=80
```
然后重启网关，串口应看到：
```
[gw] 取时成功：...
[gw] 云端已连接（IoTDA）
```

## 七、数据怎么进我们的服务器（我这边做，你也可看一下）
控制台「规则」→「数据转发」→ 新建规则 → 数据来源选 **设备属性 / 设备消息**（注意：**没有「设备事件」这个来源**，见详细指引 §6.0）→ 转发目标选 **HTTP 推送** → 地址填
`http://123.206.99.28/api/iotda/webhook?token=a3b27ab6…`（完整 token 我给）
