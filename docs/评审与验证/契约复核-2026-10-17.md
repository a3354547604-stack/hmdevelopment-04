## 4. 船长指定的四项复核结论

1. **§3 帧字节序/CRC**：算法、字节序、CRC 覆盖范围**正确**；3 条完整样例帧逐字节可复现，**足以支撑编解码单测**。缺陷是另外 3 条样例被省略（M1）——验收脚本只对这 3 条做硬断言，其余用「自编码→自解码」往返验证。
2. **§8.4 跌倒迟滞 + §9 错误码**：状态机语义**正确且可测**（进入即时、退出双条件、30 s 抑制不重置 push_count、人工闭环）；问题集中在 §9 的 `result=1502` 越界（**B2**）、引用错（M3）、采样来源未定义（M2）。
3. **§4.1 IoTDA 鉴权**：4 段 ClientId / HMAC-SHA256 / 64 位小写 / UTC `YYYYMMDDHH` / QoS1 / 禁 will-retain **口径正确**。风险不在算法而在**取时**与**参数顺序**（**B3**）。
4. **接线表（雷达供电 / MQ-2）**：电气结论**正确**——雷达独立 3.3 V/1 A、纹波 ≤50 mV、峰值 600 mA、绝不占 9 脚；MQ-2 必须 5 V 加热（172 mA）、`Vs` 超 3.3 V 必须 1:1 分压、IO09 禁外部上拉。唯一硬件采购风险是「LDO 1 W 热耗」（**M9**）；**实物是否达标仍待用户按 CAL-W-05/08/09 实测**。

## 5. 复现方式

```bash
# 本次复核的数值证据（独立实现，不读契约结论）
python3 - <<'PY'
def crc16(d):
    c=0xFFFF
    for b in d:
        c^=b
        for _ in range(8): c=(c>>1)^0xA001 if c&1 else c>>1
    return c
assert crc16(b"123456789")==0x4B37
for js,seq,tp in ((b'{"cmd":"poll","id":7}',4,0x11),
                  (b'{"ack_seq":1,"result":0}',6,0x10),
                  (b'{"cmd":"set_threshold","key":"no_motion_min","value":30}',5,0x11)):
    fr=bytes([0x01,tp])+seq.to_bytes(2,'little')+len(js).to_bytes(2,'little')+js
    c=crc16(fr); print(seq,tp,len(js),"CRC=%02X %02X"%(c&0xFF,c>>8))
print(len('{"sn":"M1","ts":1760000000000,"type":"gas","payload":{"smoke":320,"lpg":180,"co":12,"temp":24.5,"humi":56.2},"seq":12,"req_id":7,"fw":"0.1.0"}'))
PY
```
