## 4. 制作与合规要点

1. **导出参数**：1080×1920 竖屏（App 画面为主）、H.264、码率 6–8 Mbps、AAC 128 kbps → 5 分钟约 40–70 MB，**稳过 100MB 红线**；导出后按 `00` §5 的 `ffprobe` 命令核一遍。
2. **字幕**：全程中文字幕（口播听不清也能看懂）；**Mock 段与未验证段的字幕必须显式写「Mock 演示」「待实测」**。
3. **画面标注**：App 顶部数据源标签显示「离线演示数据」时，别裁掉——它本身就是诚实证明。
4. **匿名**：不出现学校/团队/老师/真实姓名/手机号/真实 Wi-Fi 名与口令；拍前清通知栏（`07` §6）。
5. **片头片尾不写校名**；如需署名，写「参赛队」。
6. **剪辑顺序**：先按本表粗剪到 300 s，再逐段砍（每段先砍口播停顿，别砍关键帧）。
7. **备份**：原始录屏保留在 `harmony-app/deliverables/现场素材/`（**该目录不入库**，避免仓库体积膨胀），交付前只把成片 `演示视频.mp4` 放进 rar。
