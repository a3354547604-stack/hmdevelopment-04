## 2. 生成命令（可复现）

```bash
# WSL 的 python3 没有 python-docx / python-pptx，必须用随 DSH 分发的 Windows Python
# 路径里的 <本机用户> 替换成当前 Windows 用户目录名（文档一律不写真名，R2 匿名口径）
PY="/mnt/c/Users/<本机用户>/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/python.exe"
cd <仓库根>
"$PY" "$(wslpath -w tools/make-submission-docs.py)"
```

脚本只读 `10-说明文档正文.md` / `11-PPT正文.md`（唯一真源），重跑即覆盖 `dist/` 两个成品；
脚本末尾打印自检 JSON（版式/占位框/页数），任一项不符即非 0 退出。

### 2.1 终版导出（t132：用户给出校名/队名 → 一条命令出终版）

> **口径写死（t132 / PM 裁定 m04614）**：**提交只允许文件名带校名队名；正文 / 封面 / 页脚 / 文档属性一律匿名。**
> `--name-in-content` 只是显式破例开关，**提交时永远不加**（加了即违反主办方通知 R2「所有材料内容中均不得出现
> 参赛团队、指导老师、院校等相关信息」）。此处与卡面早期措辞「封面出现校名」冲突时，以本行为准。

```bash
# 冻结复核通过、用户给出真实校名与队名之后，做唯一一次终版导出：
"$PY" "$(wslpath -w tools/make-submission-docs.py)" --school "<学校名>" --team "<队名>"

# 先自证参数与匿名口径（假校名队名跑 16 条断言；产物只写系统临时目录，不碰 dist/）：
"$PY" "$(wslpath -w tools/make-submission-docs.py)" --self-test
```

- `--school` / `--team` **只替换文件名**里的 `XX学校` / `XX队` 占位（R7：rar 命名「赛题序号+赛题名称+XX 学校团队名称」）。
  正文与文档属性**保持匿名**（R2：所有材料内容中均不得出现参赛院校、团队、指导老师信息）——
  封面仍只写作品名称、赛题与日期，队名只出现在文件名里。
- 真要把校名/队名写进封面（**违反 R2**，仅当用户明确要求时）再加 `--name-in-content`；脚本会在自检里把
  「当前是哪种口径」逐条打印，避免悄悄改错。
- **不传参数时行为与冻结期完全一致**：文件名仍是 `…+XX学校XX队.docx/.pptx`，内容匿名（自检 B1–B4 条）。
- 导出后**必须**在报告与本文档记「**体积 + 导出时点（+08:00）+ 对应提交号**」（D11）；**不要**拿 sha256 当防伪（原因见 §5）。
- `--self-test` 的 16 条断言：① 三份产物文件名含校名+队名且符合「赛题四+题名+学校+队名」；② 产物内 0 处
  `XX 学校` / `XX 队` 残留；③ docx/pptx 封面出现校名队名（仅 `--name-in-content` 口径）；④ 匿名扫描
  （本机用户名 / 本机绝对路径 / Windows 用户名）0 命中；⑤ 默认口径文件名仍为占位版、内容匿名、文档属性作者为
  `参赛队`；⑥ 默认口径连跑两次**内容**一致（成员级指纹）；⑦ 只给 `--school/--team` 时内容与默认口径一致
  （只换文件名）；⑧ 结构自检（提交版 15 页 / 备用页 8 页 / 宋体·小四·1.5 倍行距 / 页脚 PAGE 域）。

## 3. 版式与结构核对（脚本自检 + 渲染抽查）

**docx（设计方案）**

- 正文 **宋体 + 小四（12 pt）+ 1.5 倍行距**（脚本自检 `docx_normal_15x: true`、`docx_eastAsia_songti: 1359` 个 run、`docx_line_360: 4`）；标题黑体。
- 结构：封面 → 目录 → 第 1–6 章（与 `01-说明文档大纲.md` 的 35 个小节逐节对应）→ 附录 A/B/C → 附录 D（**内部待补清单，提交前删除**）。
- 页码：页脚居中页码域（封面不显示页码）；目录为 Word 目录域并写入 `w:updateFields`，
  Word 打开时会自动刷新出带页码的目录；若未刷新，`Ctrl+A` → `F9`。
- 每章末尾一个「【占位·待补素材】」框，共 6 个，写明该章需要的图号与建议尺寸/状态；全文 22 张表。

**pptx（答辩 PPT）**

- **两份文件**、均为 16:9（12191695×6858000 EMU）：
  - **提交版**（进材料集）：**15 页** = 封面 1 + 讲演 `P01–P14`（14 页 / 560 s）；15 页均含讲者备注；14 个配图占位框。
  - **备用页**（答辩自用、**不进材料集**）：**8 页** = 说明页 1 + `B1–B7`（7 页）；7 页含讲者备注（说明页无）。
- **10 分钟硬约束只算讲演 14 页**（官方通知对 PPT 无页数限制；15 页是内部口径）；每页标题 + ≤3 条要点 + 配图占位框（标图号）。

**匿名收口（R2，t84 内）**

- 生成时发现封面与 P01 要点里有「参赛队（不写校名/指导者/选手姓名）」这类字样：虽然是提示语而非真实身份，
  但会被投影到封面、也会被匿名扫描命中，故**从内容中移除**——docx 封面只留「赛题四 / 作品名称 / 参赛作品设计方案 / 日期」，
  pptx 封面同口径，匿名要求改写进**讲者备注**（`11-PPT正文.md` P01 要点 3 同步改为「封面信息：作品名称 + 赛题 + 日期（匿名要求见 `00` §4）」）。
- 成品匿名扫描（python-docx / python-pptx 提取 docx 全文+表格、pptx 形状+备注，按
  `tools/pack-submission.py` 的 `IDENTITY_PATTERNS` 口径匹配「院校/角色类词」与「本机用户名或
  Windows 用户目录字面」）：**docx 0 命中、pptx 0 命中**；
  `docProps` 作者/最后修改者均为「参赛队」占位，`Company` 为空（docx）或「参赛队」（pptx）。

**渲染抽查**（LibreOffice Kit，仅用于视觉核对，不代表 Word 保真）：docx 封面 / 目录 / 正文表格 /
第 5 章占位框页，pptx 提交版封面 / P12 / P13、备用页 B5 均渲染正常，无缺失字体告警（pptx 为 0）。

## 5. 未验证与边界（不得往前写）

- 本机**无 hdc 设备、无模拟器、`/dev/kvm` 不可写**：所有界面截图与现场录屏一律标「待实测」，
  **不得**用 `04-页面预览图/` 的设计预览图冒充真机截图。
- 4G 模组回传与语音播报为「**扩展设计，本原型未实现**」（D9）；`presence` / `last_motion_ts` 属 P1；App 不做配网页（配网走网关 SoftAP + 手机浏览器）；本原型不设本地声光报警器。
- 产物指纹口径（D11）：docx/pptx 只写「体积 + 导出时点 + 提交号」，**不用 sha256 当防伪**。
  t132 实测原因：docx/pptx 是 zip，**zip 条目时间戳 = 生成时刻**（与 HAP/APK 同理）——同样输入连跑两次，体积与解包后的成员内容都一样，但文件 sha256 必然不同。可复现的是「解包后各成员的内容」（脚本自检比的就是这个：成员级指纹），所以 sha256 只能在**标注当次**时引用。
- 匿名（R2）：文件名里的 `XX学校XX队` 是 R7 允许的唯一身份位；正文、备注与文档属性已清空作者/单位。
