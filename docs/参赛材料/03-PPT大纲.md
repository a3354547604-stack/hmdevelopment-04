## 1. 逐页大纲

### P01 封面（15 s）
- **要点**：① 作品名称 ② 赛题四 ③ 参赛队（**不写校名/老师/选手姓名**）
- **配图**：一张系统全景缩略图做背景（图 3-1 淡化）
- **讲者备注**：一句话定位就过——「给独居老人的非接触居家安全监测与应急辅助系统」。不要念页面上没有的内容。

### P02 问题与目标（30 s）
- **要点**：① 独居老人突发意外无法及时求助（跌倒/疾病/燃气）② 现有方案依赖穿戴设备或摄像头（老人不用、隐私顾虑）③ 我们的目标：非接触感知 + 本地优先报警 + 子女端闭环
- **配图**：图 1-1 风险与响应链路
- **讲者备注**：只讲痛点与目标，别展开技术。**不要**承诺赛题之外的功能。

### P03 系统总体架构（50 s）
- **要点**：① 五层：节点（3 个）→ 汇聚 → 网关 → 云（IoTDA + 服务器 + MySQL）→ App ② P0 范围＝1 汇聚 + 3 节点闭环 ③ 端到端：传感器 → 阈值 → 星闪 → 网关 → 云 → 手机
- **配图**：图 3-1（主图，全屏）
- **讲者备注**：这页是全场骨架，讲清「谁和谁说话」；强调**网关是唯一上云出口**。

### P04 软硬件选型（40 s）
- **要点**：① 硬件：RK2206 小凌派网关 + WS63 节点/汇聚 + MQ-2/AHT20/雷达/门磁/PIR/433 ② 软件：OpenHarmony + ArkTS（API 12）、FastAPI + MySQL 8 + Docker、华为云 IoTDA ③ 选型理由：星闪低功耗自组网解决 Wi-Fi 覆盖、2 核 2G 内存预算决定不用长连接
- **配图**：图 4-1 硬件拓扑 + 表 4-1（精简到 6 行内）
- **讲者备注**：**只讲实际采购/实际使用的型号**；价格不要出现在这页；**语音模块与 4G 模组不进「已选型」**，按 D9 只在「扩展设计」处各提一句（P06/P11）。

### P05 南向：数据采集与星闪自组网（50 s）
- **要点**：① 节点实时采集 + 基础阈值算法识别异常 ② WS63 星闪 SLE 自组网：节点广播 + 汇聚客户端，解决 Wi-Fi 覆盖不全 ③ 板级实测证据：烧录/启动/ADC 修正/雷达首帧解析
- **配图**：节点实物 + 汇聚实物；SLE 启动日志截图（`ws63-firmware/doc/3-SLE启动日志-2026-10-16.txt`）
- **讲者备注**：这段是「真做过」的部分，可以讲得实；**数值标定说「已按实测修正 ADC 分压」**，别报具体标定精度除非有记录。

### P06 本地预警与自助求助（40 s）
- **要点**：① 异常 → 网关 GPIO 声光报警（断网也能报）② 433 实体按键 SOS（`source=button`），不依赖 App/网络 ③ **扩展设计**：可接 DFPlayer TF 卡语音模块播报预设求助语（如「我需要帮助」），**本原型以声光 + App 推送替代、未实现**（D9）
- **配图**：声光报警器/433 实物；S04（App 首页紧急态）
- **讲者备注**：强调「给不会用手机的老人一个实体按键」；**App 内没有一键呼救按钮**，别口误；语音按 D9 口径只讲「扩展设计」，**不要说已实现/待实测**。

### P07 网关：本地规则与上云（45 s）
- **要点**：① 本地规则引擎（离家模式、门久开、无活动）② 断网本地报警 + 恢复后补传 ③ 配网走网关自带 H5 页面（`192.168.4.1`，手机浏览器即可）
- **配图**：图 3-2 数据流 + 配网页截图（V01 静帧）
- **讲者备注**：配网这页必须说明「App 内配网为 P1，P0 走浏览器 H5」——评委看到 App 里没配网按钮时会问，**主动讲掉**。

### P08 云端：服务器与数据契约（45 s）
- **要点**：① 18 个 REST 端点 + webhook，接口契约是唯一技术事实源 ② 告警送达：未确认队列 + 分级重推（`retry_count`/`next_retry_at`）③ 部署：Docker Compose（db+api 仅绑 127.0.0.1）、测试库 `_test` 隔离
- **配图**：图 3-4 状态机 + 契约 §6 端点清单（精简表）
- **讲者备注**：**别念 18 个端点**，挑 3 个（登录/告警列表/处置）说；「契约先行」是我们工程化的亮点，可强调。

### P09 应用端：五页与实时展示（40 s）
- **要点**：① 五页：登录 / 首页实时 / 告警列表与详情 / 报表 / 设置 ② 首页展示传感器状态、设备在线、网关十四属性（配网状态、已绑定节点）③ 数据源标签区分「在线服务器 / 离线演示数据」

- **讲者备注**：截图**若来自模拟器要说明**；讲「离线演示数据」标签是设计上的诚实标记。

### P10 事件闭环：确认与处置（45 s）
- **要点**：① 预警 → 子女确认 + 填处置结果（已电话联系/已上门查看/误报/其它）② 处置记录 → 居家安全日志，长期跟踪 ③ 重复处置走 409/1301，避免重复响应

### P11 数据分析：周报 / 月报（40 s）

## 3. 制作规范

1. **一页一主题**：每页要点 ≤3 条、每条 ≤15 字；**字少图大**（评委 3 米外能看清）。
2. **字号**：标题 ≥32 pt、正文 ≥20 pt、图表标注 ≥16 pt；字体用系统默认无衬线（演示电脑缺字体不崩）。
3. **配色**：主色一个 + 强调色一个（可用 `harmony-app/deliverables/04-页面预览图/` 的界面配色）；红只用于报警态。
4. **动画克制**：只用「出现」与页面切换；不用飞入/旋转。
5. **截图规范**：每张图下加一行小字 `S0x 页面名 — 证明：<验收项/演示动作>`（取自 `07` 的「证明」列）；**模拟器截图要标「模拟器」**、**设计预览图要标「设计预览」**。
6. **匿名**：封面与页脚不写校名/老师/姓名；截图里不出现通知栏个人信息（`00` §4）。
7. **排练计时**：按上表逐页掐表，超时的页先砍口播、再合并页；**总时长按 9:30 练**（现场容易讲慢）。
8. **兜底**：把 `演示视频.mp4` 嵌在 P14（或本地备一份），现场设备故障时直接放视频。
