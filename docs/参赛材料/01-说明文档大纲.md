## 0. 体例与排版规范

### 0.1 排版硬指标（交前人工核对）

| 项 | 要求 | 说明 |
|---|---|---|
| 正文字体 | **宋体** | 标题可用黑体，正文必须宋体 |
| 字号 | **小四号** | 代码/命令行可用五号等宽字体 |
| 行距 | **1.5 倍** | 全文统一，含图表标题 |
| 页数建议 | 25–35 页（不含附录） | 赛题未限页数；过短显得薄，过长评委不看 |
| 图表 | 每图/表都要有编号与标题（`图 3-1 系统总体架构`） | 正文必须引用到（「如图 3-1 所示」） |
| 匿名 | 全文不得出现学校/学院/团队/指导老师/选手姓名（`00` §4 自检） | 封面作者栏写「参赛队」即可 |
| 文件属性 | 交前清空 docx 的作者/单位字段（`00` §4 第 3 条命令） | 常见漏点 |
