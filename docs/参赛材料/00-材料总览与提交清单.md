## 4. 匿名检查项与自检方法

**检查项（每份材料、每张图、每段视频过一遍）**：不得出现 ①学校/学院/大学名称 ②团队名/队名 ③指导老师/教师姓名 ④选手真实姓名 ⑤真实手机号/微信号/QQ 号 ⑥真实住址 ⑦真实 Wi-Fi 名称与口令 ⑧含上述信息的截图（通知栏、浏览器书签栏、桌面壁纸）。

**允许出现**：`daughter01` / `P@ssw0rd!`（mock 假账号）、`192.168.4.1`、`ElderCare-XXXX`、`XX 学校`/`XX 队` 占位符、rar 文件名里的真实校队名（R7 要求）。

**自检命令（在仓库根跑）**：

```bash
# 1) 文本材料：列出所有可能涉及身份的词，逐行确认（不是「零命中」而是「命中即解释」）
grep -rniE "学校|学院|大学|团队|队名|指导老师|指导教师|姓名" docs/参赛材料/
# 期望命中只有三类，均可保留：
#   (a) 占位符 `XX 学校` / `XX 队`
#   (b) 规则引用句（「不得出现参赛团队、指导老师、院校」等）
#   (c) 界面业务文案（处置动作「已电话联系」等）——不是身份信息
# 出现任何真实校名/人名/队名 = 不合格

# 2) 图片/视频元数据（EXIF 里常带作者名/设备名）
exiftool -Author -Artist -Copyright -Software deliverables/现场素材/*.png 2>/dev/null

# 3) 文档属性（docx/pptx 的作者字段）
unzip -p 说明文档.docx docProps/core.xml | grep -i "creator\|lastModifiedBy"
```

> 本骨架四份文件在 2026-10-18 的自检结果：命中 **16 行**，逐行核对后全部属上述 (a)(b)(c) 三类（占位符 / 规则引用句 / 界面业务文案），**0 条真实身份命中**。

## 5. 大小 / 时长红线自检方法

| 红线 | 命令 | 通过标准 |
|---|---|---|
| 视频 ≤5 分钟、≤100MB | `ffprobe -v error -show_entries format=duration,size -of default=nw=1 演示视频.mp4` | `duration ≤ 300`（秒）、`size ≤ 104857600`（字节） |
| 视频格式 | `ffprobe -v error -select_streams v:0 -show_entries stream=codec_name -of csv=p=0 演示视频.mp4` | `h264`（评审最稳） |

| rar 命名 | `ls 赛题四*.rar` | 形如 `赛题四+独居老人居家安全监测与应急辅助系统+XX 学校XX队.rar` |
