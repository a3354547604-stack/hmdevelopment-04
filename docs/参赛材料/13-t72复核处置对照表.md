**② 引用解析（全部带行号引用逐条核对）**

把下面脚本存成 `refs.py` 后 `python3 refs.py`（在仓库根运行）：逐条打印「材料位置 → 被引行前 20 字」，起始行是空行或整段全空即判失败。

```python
import re, pathlib, sys
ROOT = pathlib.Path('.').resolve()
FILES = ['00-材料总览与提交清单.md','01-说明文档大纲.md','02-5分钟视频分镜.md','03-PPT大纲.md',
         '10-说明文档正文.md','11-PPT正文.md','12-视频文案与镜头表.md']
PREFIX = ['','docs/','docs/技术/','docs/评审与验证/','docs/执行/','docs/技术笔记/','docs/参赛材料/',
          'harmony-app/','harmony-app/deliverables/','harmony-app/entry/src/main/ets/','server/',
          'server/app/','server/tests/','rk2206-gateway/','rk2206-gateway/doc/','ws63-firmware/',
          'ws63-firmware/doc/','tools/','tools/test/','tools/test/review/']
PAT = re.compile(r'`?([\w\u4e00-\u9fff./\-]+\.(?:md|py|ets|ts|sh|json|json5|txt|sql|yml|yaml|h|c|cpp)):(\d+)(?:-(\d+))?`?')
ok = bad = skip = 0
for fn in FILES:
    text = (ROOT/'docs/参赛材料'/fn).read_text(encoding='utf-8')
    for m in PAT.finditer(text):
        rel, a = m.group(1), int(m.group(2)); b = int(m.group(3)) if m.group(3) else a
        tgt = next((ROOT/(p+rel) for p in PREFIX if (ROOT/(p+rel)).is_file()), None)
        if tgt is None:
            skip += 1; print(f'[SKIP] {fn} {rel}:{a} 文件不存在（未产出交付物/命令）'); continue
        lines = tgt.read_text(encoding='utf-8', errors='replace').split('\n')
        if b > len(lines) or not lines[a-1].strip():
            bad += 1; print(f'[FAIL] {fn}:{text[:m.start()].count(chr(10))+1} {rel}:{a}-{b}'); continue
        ok += 1
        print(f'[PASS] {fn}:{text[:m.start()].count(chr(10))+1} {rel}:{a}-{b} → ' +
              ' ｜ '.join(f':{i} {lines[i-1][:20]!r}' for i in range(a, b+1)))
print(f'\n解析成功 {ok} 条，失败 {bad} 条，跳过 {skip} 条')
sys.exit(1 if bad else 0)
```

**本机实跑结果**：`解析成功 67 条，失败 0 条，跳过 2 条`（退出码 0）。两条跳过均为尚未产出的交付物（`演示视频.mp4` 等），非缺陷。修复前该脚本报 **14 条失败**，与 t72 报告的 F-01(10) + F-02(2) + F-06(2) 逐条对应。
