## 3. 文档状态标签

每份文档的正文头部会标状态，含义固定为三种：

- **有效** —— 现在仍然成立，可以照它做。
- **历史** —— 只记录「当时发生过什么」，结论可能已被推翻；引用前先看它指向的新文档。
- **待实测** —— 结论来自静态分析或厂商资料，还没有上板/上线验证过，不能当作已验证事实。

约定（源自 [项目章程.md](项目章程.md) §9）：旧文档只归档不删除；文档头三行写 owner / 更新时间 / 状态。
